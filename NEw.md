## Linguistic vs. ML Mechanics
Natural language vulnerabilities map directly to underlying transformer self-attention distributions and probabilistic sequence modeling parameters [VERIFIED][cite: 7, 11]. When input prompts contain polysemous terms, ambiguous prepositions, or non-standard syntax, the self-attention mechanism distributes attention weights across multiple unrelated concept vectors [VERIFIED][cite: 6, 11].

Mathematically, input ambiguity increases output entropy $H(X)$:

$$H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$

High entropy $H(X)$ causes the model to fit on pre-training noise, treating low-probability outlier points as valid completions [INFERRED][cite: 7, 11]. Technical writing standards—such as using strict action verbs (e.g., "execute", "shut", "extract" instead of ambiguous phrasing like "run", "close", "get") and specifying explicit boundary conditions—minimize next-token perplexity [VERIFIED][cite: 7, 9, 11]. This forces the self-attention layer to concentrate probability mass $P(x_i)$ strictly on the target output distribution [INFERRED][cite: 6, 11].
